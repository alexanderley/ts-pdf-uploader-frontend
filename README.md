# Fullstack Application - PDF Upload

This repository contains the frontend part of a fullstack application built using React.js, Typescript, and Vite on the frontend, and Node.js, Express.js, MongoDB, and various packages for file handling on the backend. The application allows users to log in and upload PDF files to a database. Users can access the file upload form and view uploaded files on the /upload page after successfully logging in.

## Technologies Used

### Frontend

React.js: A popular JavaScript library for building user interfaces.
Typescript: A statically typed superset of JavaScript for improved code quality.
Vite: A fast and minimalistic build tool for React applications.

### Backend

Node.js: A runtime environment for executing JavaScript on the server.
Express.js: A web application framework for building robust APIs.
JSON Web Tokens (JWT): Used for user authentication and authorization.
Multer: A package for handling file uploads and converting files to BSON/Bin24 code.
pdf-parse: Used for extracting data from uploaded PDF files.
MongoDB: A NoSQL database for storing user data and uploaded PDF files.

## Getting started

### Clone this repository to your local machine

git clone https://github.com/alexanderley/ts-pdf-uploader-frontend.git

### Go to directory

cd frontend

### Install dependencies

npm install

### Start the server

npm run dev

## Open your browser

Open your web browser and access the frontend application at http://localhost:5137.
